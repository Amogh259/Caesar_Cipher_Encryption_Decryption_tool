# 🔐 CRYPTOVA – Python Caesar Cipher Encryption-Decryption Tool

**Your Words, Your Secret.**

CRYPTOVA is a Python-based encryption and decryption tool that allows users to securely transform messages using the Caesar Cipher technique. Users can encrypt and decrypt text by specifying a shift key. The tool also supports uppercase letters, lowercase letters, numbers, spaces, and special characters.

## ✨ Features

- **Message Encryption:** Encrypts messages by shifting letters and numbers using a user-defined key.
- **Message Decryption:** Decrypts encrypted messages using the same shift key.
- **Case Preservation:** Maintains uppercase and lowercase letters in the original message.
- **Number Encryption:** Supports shifting digits from 0 to 9.
- **Special Character Support:** Preserves spaces, punctuation, and special characters without modification.
- **Interactive Menu:** Simple menu-driven interface for easy navigation.
- **User-Friendly Output:** Clear instructions and feedback for users.

## 🛠️ Technologies Used

## 🚀 Installation & Setup

Follow these steps to run CRYPTOVA on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/Amogh259/Caesar_Cipher_Encryption_Decryption_tool.git
```

**2. Navigate to the project directory**

```bash
cd Caesar_Cipher_Encryption_Decryption_tool
```

**3. Run the Python program**

```bash
python caesar_cipher.py
```

If the Python file or repository has a different name, replace it with the actual name.
